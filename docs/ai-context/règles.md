# Règles de codage

- Utiliser TypeScript avec des interfaces précises ; éviter `any`.
- Nommer les composants en PascalCase et conserver les composants réutilisables dans `components/`.
- Centraliser les contenus réutilisés dans `data/`.
- Utiliser `use client` uniquement pour les composants interactifs ou animés.
- Préserver Tailwind CSS et la direction Roven dans `app/globals.css`.
- Ne pas commiter `.next/`, secrets ou fichiers générés.
- Vérifier avec `npm run lint` et `npm run build` lorsque possible.
- Mettre à jour `tasks.md` et `memory.md` après chaque session importante.
