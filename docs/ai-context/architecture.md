# Architecture du projet

## Stack

- Next.js 14.2 avec App Router, React 18 et TypeScript.
- Tailwind CSS 3.3.
- Framer Motion, Lucide React et `react-typewriter-effect`.
- Déploiement et hébergement : **[À REMPLIR]**.

## Structure

- `app/` : layout, page d’accueil et styles globaux.
- `components/` : Header, Hero, About, Skills, Projects, Gallery, TerminalDemo, Contact et Footer.
- `data/` : contenu du portfolio.
- `types/` : déclarations TypeScript.
- `public/` : images et assets.

La page d’accueil compose les sections du portfolio. Le traitement du contact et l’analytics : **[À REMPLIR]**.
