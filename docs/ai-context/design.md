# Direction UI/UX

## Direction visuelle

Le portfolio utilise le thème Roven : interface sombre, élégante et premium, avec accents dorés.

## Palette et typographie

- Fond : `#0A1628`.
- Cartes : `#1A2A3A`.
- Accent : `#D4AF37`.
- Accent clair : `#E8C65A`.
- Texte principal : `#F5F5F5`.
- Texte secondaire : `#8A9BA8`.
- Titres : Playfair Display ; texte courant : Inter.

Vérifier contraste, clavier, focus, mouvement réduit et responsive mobile. Exigences WCAG détaillées : **[À REMPLIR]**.
